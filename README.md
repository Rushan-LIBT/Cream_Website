# Cream - Premium Lifestyle Website

A supiri, minimalist, and premium website designed with pure HTML, Tailwind CSS (CDN), and JavaScript. No Node.js or build steps required.

## How to Run

Simply open `index.html` in your web browser.

## Features

- **Premium Design**: Custom "Cream" color palette and typography (Outfit font).
- **Responsive**: Fully responsive design for mobile, tablet, and desktop.
- **Animations**: Smooth scroll animations using AOS library and custom CSS transitions.
- **No Dependencies**: Uses CDN for Tailwind CSS and AOS, so no `npm install` is needed.
- **Multiple Pages**:
  - Home (`index.html`)
  - About (`about.html`)
  - Services (`services.html`)
  - Contact (`contact.html`)

## Customization

You can edit the `tailwind.config` script block in the HTML files to change colors or fonts.
Images are currently placeholders from Unsplash. You can replace them with your own images in the `assets/img` directory.

Enjoy your smooth, cream experience!
